# 优酶研途 1.0.2

电脑版和安卓版的启动页已设为约两秒：正常初始化时，约 1.5 秒开始淡出，约 2 秒进入规划界面。初始化较慢时继续等待页面就绪，避免露出空白界面。「优酶研途」和「玩家C出品」保持完整展示。

电脑版实际打包程序中测得启动页约 2.04 秒；已核对名称、版本、44 个规划节点和内嵌文件。安卓更新为 versionCode 3，沿用原应用标识及发布签名，可覆盖旧版升级。

安装前请在旧版导出 JSON 备份，关闭旧版后覆盖安装；安卓不要先卸载。个人数据仍保存在原有本机位置。

本目录仅保留 1.0.2 发布安装包、手机工程及主屏幕部署包；旧安装包和旧网页部署压缩包已清理。原始 Excel 与项目源码继续保留。线上网站本次未发布更新。

Android 安装包尚未在实体手机验收；iPhone 提供主屏幕部署包和原生工程，没有可直接安装的 IPA。Windows 安装包未做商业代码签名。文件校验值见各安装目录的 SHA256SUMS.txt。
