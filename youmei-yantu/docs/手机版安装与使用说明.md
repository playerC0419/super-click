# 优酶研途手机版

## 安卓：优先使用 APK

1. 将 Youmei-Yantu-1.0.2-android.apk 下载到安卓手机并打开。
2. 如系统询问来源安装权限，只按提示允许当前下载应用安装此包；不要关闭系统安全防护。学校或单位管理的手机可能限制自行安装。
3. 安装后打开「优酶研途」，无需访问网站、注册账号或使用 VPN。

1.0.2 版本的深蓝分子轨迹启动页展示约两秒（含淡出），署名「玩家C出品」。应用标识、发布签名和数据键保持一致，可在旧版上覆盖升级；请先导出 JSON 备份，不要先卸载旧版。

最低安装版本为 Android 7（API 24），建议使用较新的安卓系统，并保持 Android System WebView / Chrome 更新。尚未在实体手机验收；部分厂商的安装、文件选择和分享界面可能不同。纯鸿蒙且不支持 APK 的设备不能使用此包。

全部节点和指南内置在应用中。默认卡片列表便于手机编辑，也可切换时间线横向查看三年排期。官网通知、网盘材料链接等外链需要联网。具体报名及培养节点仍请核对当年通知。

## 导入原规划

在电脑版或原网页「备份 / 导入」导出 JSON，把文件传到手机，再在手机版同一入口导入。导入会替换当前规划，请先保留当前备份。CSV 用于阅读，不用于恢复。

## 保存、导出和提醒

应用内修改保存在本机，同时写入原生持久存储和应用内部恢复副本。手机、电脑和其他人的数据互相独立，不自动同步。**卸载或清除应用数据会删除这些记录；请定期导出 JSON 并保存到应用之外。**

导出 JSON、CSV、ICS 时打开手机系统分享菜单，选择「保存到文件」、网盘或发送给自己；是否有对应选项取决于手机安装的应用。请确认文件真正保存后再退出。取消分享不等于完成备份。

「打印当前规划」尝试打开 Android 系统打印界面，可按设备支持情况选择「另存为 PDF」。日历提醒需将 ICS 导入日历应用；此版没有关闭应用后的后台推送服务。

应用不自动升级。后续使用同一签名的新版 APK 覆盖安装前，请先导出 JSON。若签名不一致，系统通常不允许覆盖安装，不要为强行升级而先卸载重要数据。

## iPhone：先尝试免费主屏幕版

当前没有提供可直接安装的 IPA。iOS 原生工程已准备，但仍需 Mac/Xcode 构建和 Apple 签名；云端构建工具也不能替代实体 iPhone 所需签名。

免费方式：用 Safari 打开已部署的手机版 HTTPS 地址，点「分享 → 添加到主屏幕 → 添加」。如显示「作为网页 App 打开」，请开启。从主屏幕图标启动后，等待显示「离线可用」，再用飞行模式验证。不要在微信内置浏览器里尝试安装。

当前原 chatgpt.site 托管地址的模拟断网重启检查未通过，因此不能保证该地址的离线启动。建议把主屏幕版 ZIP 上传到你自己的 Netlify 项目后，用实体 iPhone 复测；在验证前应保持联网，保留外部 JSON 备份。这不影响安卓 APK 的离线运行方式。

同目录的「优酶研途-1.0.2-安卓与iPhone主屏幕版.zip」可直接作为新版本上传到你的 Netlify 项目，并将 Production visibility 设置为 Public。不需要购买域名。首次安装仍需能够访问该网址，不能保证任何托管地址在所有大陆网络都能直连。本次更新未修改线上托管网站；新版名称与启动页已包含在此部署包中。

安装前从原网页导出 JSON，再在主屏幕版本中导入，避免不同浏览器/独立应用存储空间造成记录看似丢失。iPhone 导出会尝试打开系统分享；选择「存储到文件」。如果浏览器不支持该文件的系统分享，则回退为下载。

主屏幕版不是 App Store 原生应用。清理网站数据、卸载、换域名或系统回收存储可能影响数据；请保留外部 JSON 备份。没有实体 iPhone / Safari 测试结果，当前只验证了手机尺寸的 Chromium 模拟。
