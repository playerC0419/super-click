# 优酶研途 · Windows 离线桌面版

适用：Windows 10/11，Intel/AMD 64 位电脑。此版本不包含 macOS、手机或 ARM64 原生安装包。

## 安装和分享

把 Youmei-Yantu-Setup-1.0.2-win-x64.exe 安装包发给其他人即可。安装到当前用户目录，无需安装 Node.js、Python 或搭建服务器。可选择安装目录，安装后从桌面或开始菜单打开「优酶研途」。

新版启动页采用深蓝背景、分子轨迹图形与渐变动画，并展示「玩家C出品」，正常展示时间约两秒（含淡出）。初始化完成后自动进入规划界面。由旧版升级时保留相同应用标识和数据目录；建议先导出 JSON，再关闭旧版并运行新版安装包。

安装包包含全部页面资源、通用节点与桌面运行环境。三年时间线、节点编辑、竞赛/项目/考证指南、材料记录、职业路线和精力评估均可离线使用。官网通知、材料网盘等外部链接由系统浏览器打开，需要联网。

该版本未购买商业代码签名证书，Windows 可能提示未知发布者。请只从可信渠道取得文件，核对随包提供的 SHA-256；如组织策略阻止运行，应请管理员审核，不要关闭安全防护。

## 从网页版迁移

1. 在原网页选择「备份与迁移」，导出 JSON。
2. 在桌面版选择「备份与迁移」，导入该 JSON。
3. 核对节点、材料、备注和截止日期。请保留原备份文件。

网页浏览器和桌面版的数据互相独立，不会自动同步。安装包不包含制作者或其他用户的个人规划。

## 保存和自动备份

编辑后自动保存在当前 Windows 用户的本机目录：%APPDATA%\YantuPlanner 。每分钟及正常退出时，在内容变化后生成 JSON 备份，保留最近 10 份。可从「文件 → 打开自动备份目录」找到文件，再通过「备份与迁移」导入恢复。

自动备份与主数据在同一台电脑，不能代替异地备份。建议定期手动导出 JSON 到其他存储设备。异常关机不一定完成退出备份；硬盘损坏、手动清除数据仍可能导致丢失。

升级时使用同一应用标识与数据目录。卸载默认保留个人数据；安装程序所在目录与个人数据目录分离。若有重要记录，升级或卸载前仍建议导出 JSON。

## 导出和打印

JSON、CSV、ICS 均可从原页面导出，桌面版会弹出保存位置选择框。日历提醒需要把 ICS 导入日历应用；程序本身没有后台定时推送。菜单「文件 → 打印 / 导出 PDF」打开系统打印界面。

## 日期和更新

节点按三年制月份模板安排，日程说明与具体报名、学院要求可能变化。使用者应核对当年学院和主办方通知，并在程序中更新。桌面版不联网自动下载模板，也不自动升级；新版本需重新下载安装。

技术：Electron 独立桌面窗口，内置页面资源，禁用页面 Node.js 权限，独立本机存储。Lucide 图标许可随资源保留；Electron/Chromium 的许可随运行环境分发。
