## 已落地的 A—J

| 方向 | 使用入口与行为 |
|---|---|
| A 连接状态 | 页面显示服务心跳、主窗口可连接/加载中/离线/端口归属异常；断线重连共用一次连接。登录和额度没有可靠接口，明确不推断。 |
| B 重试与恢复 | 仅确认从未派出的失败任务允许安全重试；状态不确定时先核对原会话，不自动重发目标。 |
| C 补充与提问 | 任务详情支持回复、材料上传；区分保存与真实领取；执行器通过 request-input/input 提问接收回复。已结束轮次可“回复并继续”。 |
| D 成果与版本 | 新回报自动保存每轮快照、SHA-256；下载历史轮次、比较新增/删除/变化文件。支持安全的文本、图片、PDF预览，PPTX/DOCX为文字概览，不等同于版面渲染。 |
| E 验收与返工 | 建任务时每行一条验收要求；逐项写实际证据；未通过项可生成返工草稿；所有检查通过并有证据后才允许接受。仍须实际检查，不能自动证明成果质量。 |
| F 项目与模型 | 新任务展开“模型、材料与验收要求”，读取真实模型、选择项目、保存目录/会话/默认模型绑定；已有任务继续原会话。 |
| G 队列历史 | 暂停后续派工、优先级、任务搜索、状态筛选、分页、归档；暂停不打断当前任务，归档不删除文件。 |
| H 通知 | 页面动态显示完成、异常和待回复；点击“启用桌面提醒”后按浏览器授权提供系统提醒。关闭控制台页面后不承诺浏览器提醒。 |
| I Windows 稳定性 | 监护检查心跳和调度进展、核对进程身份、限速重启；忙碌或不确定任务不自动重启执行器；日志轮换。原有登录启动及 WorkBuddy 普通重开接单保留。 |
| J 维护 | “备份与维护”创建本机备份、校验恢复、下载脱敏诊断、空闲重载。恢复后队列保持暂停。升级脚本先编译测试，正式替换前备份；替换失败尝试回滚。 |

## 维护操作

日常操作使用控制台“备份与维护”。恢复前所有活动/不确定任务必须确认结束；恢复后人工查看记录，再点“恢复后续派工”。

管理员命令从安装目录使用 runtime/node.exe 执行：

- scripts/windows-control.mjs status / start / stop / restart
- scripts/windows-control.mjs restore 备份编号
- scripts/windows-upgrade.mjs 升级源目录：只做编译和测试预检，不替换。
- scripts/windows-upgrade.mjs 升级源目录 --apply：校验预检、备份、空闲停止、替换代码、重启；不更改业务目录。当前版本拒绝依赖发生变化的升级包，需先准备匹配依赖。

升级源须完整包含 Windows 组件、测试及已安装依赖。不要直接覆盖上游最新版而丢掉本地 Windows 改动。改进前独立备份位于上级 gateway-backups/before-A-J-20261015-124541；新备份在 data/platform/backups 中按编号查找。
